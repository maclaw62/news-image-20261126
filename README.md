One image summing up the world news of Thursday 26 November 2026: 27 dated
stories across six regions, arranged with the day's biggest stories across
the top, medium stories beneath them, and dense smaller rows for the rest
of the day. Headlines were checked against reporting dated 26 November 2026
from Reuters, AP, Al Jazeera, BBC and CNN. The board leads with the new US
tariffs on 14 partners, the Kyiv missile strike and Zelenskiy's warning of
a coming mass strike, and the Hormuz mine claims that lifted oil prices.

## Run it

```sh
python3 main.py
```

`main.py` copies `entry.png` to `/output/entry.png`. To redraw the board
from source, run `python3 draw.py` (needs Pillow) in this directory.
